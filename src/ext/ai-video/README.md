# 视频流程业务

本目录包含全部视频业务代码。应用在 `src/app/` 显式装配；底层不引用本目录。

| 文件 | 职责 |
| --- | --- |
| `model.ts` | 图片、提示词、配置数据；业务字段校验与默认值 |
| `schema.ts` | Drizzle 定义 `ext_ai_video_nodes`，外键关联基础节点 |
| `storage.ts` | 业务数据和独立表之间的转换，参与基础保存事务 |
| `routes.ts` | 二进制图片上传、图片读取 |
| `actions.ts` | 原子创建节点、建立有向输入、排序、修改字段 |
| `config.ts` | 按前序输入顺序生成 JSON，返回缺失或错误原因 |
| `VideoEditor.tsx` | 独立视频画布入口，组合通用编辑器与视频节点、菜单和连线规则 |
| `uploads.tsx` | 记录本画布正在上传的图片节点，供依赖该图片的配置判断导出状态 |
| `components.tsx` / `styles.css` | 图片预览、输入表单、排序及 JSON 导出界面 |

图片节点保存图片路径和原文件名；提示词节点保存文本；配置节点保存输出文件名、步数和输入顺序。基础节点没有类型或提示词字段，membership 不代表视频输入。

多对一使用现有 `base_edges`，不新增端口、连线表或执行引擎。业务只接受图片/提示词连到配置的有向输入；一个来源可供多个配置使用。同来源的平行边按来源节点去重，配置只读取当前视频画布内的直接前序节点。输入顺序保存在业务表，图片编号与提示词合并都依据该顺序。

底层新增的 `attachment.put/delete` 是通用的节点数据挂载能力，使用 `namespace + nodeId` 定位；业务字段通过本目录解释。业务变更与节点创建、连线、布局一起进入同一会话、批次和 SQLite 事务；删除节点通过外键清理业务行，撤销通过会话快照恢复附加数据。

上传使用现有 Axios/Fastify，无额外依赖。浏览器检查图片可解码，服务端检查类型签名和大小。文件使用随机名存入 `data/ext/ai-video/assets/`；复制/下载的 JSON 使用相对于 `data/ext/ai-video/` 的路径，例如 `assets/AbCdEf123456.png`。原文件名只用于展示，因此同名上传不会覆盖。

上传文件在替换或删除节点后保留，以便会话撤销恢复；没有自动回收、Drive 同步、模型调用或视频文件上传。运行你自己的视频函数时，输入根目录需指向 `data/ext/ai-video/`。
