# uknode

本地优先的项目图编辑器。首页按业务选择项目并查看节点与连线列表。每个节点属于一个项目，有一份画布坐标，业务内容通过节点 ID 挂载。普通画布提供通用图编辑，视频流程支持图片、提示词和配置导出。

项目、节点、连线和保存批次统一使用 `nanoid(12)` 生成 12 位 ID（大小写字母、数字、`_` 和 `-`）。界面直接完整显示 ID，接口只接受这一种格式；SQLite 使用 TEXT 字段存储。

## 运行

需要 Node.js 24。在项目根目录运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。同一命令启动 Vite 和本地 Fastify 服务，前端的 `/api` 请求代理到服务端。

正式本地运行：

```sh
npm run build
npm start
```

打开 http://127.0.0.1:3000 。Fastify 通过官方插件 `@fastify/static` 提供构建后的 HTML、JavaScript 和 CSS，页面与 API 同源。服务仅监听本机，不把 SQLite 文件交给浏览器读取。

数据库默认位于 `data/uknode.sqlite`，首次启动自动创建目录和数据库并执行迁移。可用 `UKNODE_DATA_DIR` 指定其他目录，`PORT` 修改后端端口。数据库、依赖和构建产物不提交 Git。请始终从项目根目录运行命令。

## 数据库定义与同步

**基础表定义在 [`src/storage/schema.ts`](src/storage/schema.ts)，业务表定义在各自 `src/ext/<业务>/schema.ts`**。这些文件明确声明表名、字段、主键、外键、索引和检查约束：

| 定义 | SQLite 表 | 职责 |
| --- | --- | --- |
| `baseProjects` | `base_projects` | 项目 ID、名称、业务类型与独立修订号 |
| `baseNodes` | `base_nodes` | 节点 ID、必填的 project_id、创建与更新时间 |
| `baseEdges` | `base_edges` | 连线 ID、两端节点 ID、方向及时间 |
| `viewNodeLayouts` | `view_node_layouts` | 节点 ID 主键与 x、y 坐标 |
| `baseBatchReceipts` | `base_batch_receipts` | 各项目最近 1,000 个批次的幂等回执；没有操作内容 |
| `videoNodes` | `ext_ai_video_nodes` | 视频业务节点类型、图片、提示词、输出参数与输入顺序；定义在 `src/ext/ai-video/schema.ts` |

`base_schema_migrations` 由 Drizzle 管理，用于记录已执行的迁移；名称在 `drizzle.config.ts` 和服务启动配置中一致指定。

修改表结构的流程：

1. 修改对应的基础或业务 `schema.ts`。
2. 运行 `npm run db:generate -- --name=变更名称`，由 Drizzle Kit 生成 `migrations/` 下的 SQL 与结构快照。
3. 查看生成的 SQL。变更已有数据前，先备份当前数据库。
4. 运行 `npm run db:migrate`，将迁移应用到 SQLite；启动服务也会应用尚未执行的迁移。
5. 将表定义和迁移文件一起提交。不要只改数据库而遗漏代码定义。

升级到项目版时，Drizzle 执行一次 `0005_project_graph.sql`，清空旧图、坐标和业务记录。之后启动会读取已保存的项目。SQLite 迁移只处理数据库，图片文件位于数据目录的 `ext/ai-video/assets/`。

## 操作与保存

首页 `/` 上方选择业务，左侧创建或选择项目，右侧查看该项目的节点与连线。点击“进入画布”打开 `/?project=<项目 ID>`，点击左上角 uknode 返回当前项目的概览。

- 点击底部“新增节点”，或右键画布空白处新增；右键新增使用鼠标所在的画布位置。
- 拖动节点调整坐标。悬停或选中节点时显示连接点，从右侧连接点拖到另一节点左侧连接点创建连线。
- 点击节点，在右下角查看现有 ID 和坐标；点击连线，在同一详情卡查看端点并编辑方向。详情卡可折叠，折叠状态只保留在本页会话。
- 左键拖动空白处框选完整包含的节点；Shift 点击节点可追加选择。选区支持整体移动、删除和撤销。多选详情显示选中数量。
- 右键节点打开“新增节点／删除节点”菜单。右键未选节点会切换为单选；右键已选节点会保留多选，删除这些节点及其关联连线。空白处菜单禁用删除。
- 选中节点或连线，点击“删除选中”；删除节点会同时删除关联连线和坐标。
- 使用“撤销”“重做”或 Ctrl/⌘ Z、Ctrl/⌘ Shift Z。输入框内仍使用浏览器原生文字撤销。
- 按住空格再拖动，或按住鼠标中键拖动来平移；使用滚轮或左下角控件缩放、适应画布。
- 右键菜单支持方向键选择和 Enter 执行；按 Escape、点击外部或移动视口关闭菜单。

普通连线允许成环、自连接和同端点多条边。

编辑先更新前端内存，并按对象保留待保存的最终变更，包括删除。拖动结束提交坐标，相关修改以 300 毫秒防抖合成批次并按顺序发送。连续编辑同一业务字段在 1 秒内合并撤销记录。新建后立即删除可能提交一次无实际数据变化的删除，仍会推进修订号。后端在事务内检查修订号，依靠外键校验节点引用，再增量写入当前表。

发送中的批次固定 ID 和内容；期间的新修改进入下一批。响应丢失时重试相同批次，服务端先查幂等回执，避免重复执行。只在收到对应回执后显示已保存。服务端拒绝字段值时，客户端保留整批修改，更正字段后合并重提。修订冲突时暂停保存，保留当前页面的修改。“重新读取”需要确认放弃本页尚未确认的修改。

前端最多保留当前会话 100 个撤销动作。没有永久历史或 IndexedDB 草稿恢复；异常关闭可能丢失尚未确认的修改。切换画布或刷新会重新读取 SQLite，并重置选区、视口及会话撤销记录。若仍有修改待保存、图片正在上传或生成，离开前浏览器会提示确认。

## 代码位置与验证

| 目录 | 职责与主要文件 |
| --- | --- |
| `src/core/` | 项目、基础节点、连线及图变更。 |
| `src/runtime/` | 文档、保存批次、前端撤销和自动保存。 |
| `src/storage/` | Drizzle 表定义、项目查询、作用域检查和 SQLite 事务。 |
| `src/view/` | 通用 React Flow 画布、菜单、详情和选择状态。 |
| `src/ext/ai-video/` | 视频业务表、节点表单、参考图上传与生成、JSON 配置导出。 |
| `src/app/` | 首页、项目编辑入口、Fastify 路由与装配。 |

```sh
npm test
npm run build
```

`npm run build` 运行前后端 TypeScript 检查。测试覆盖项目隔离、一次性数据库重置、增量保存、撤销和视频配置导出。

## 视频流程编辑

在“视频流程”画布的右键菜单可新增图片、提示词和配置节点。图片节点上方预览区支持放大和上传 PNG/JPEG/WebP（最大 20 MB）。下方输入生图提示词并点「生成」即可文生图，开启「参考当前图片」可用现图进行编辑。图片节点的生图提示词单独保存，视频提示词由提示词节点提供。

启动服务前设置环境变量 `OPENAI_API_KEY`。默认图片模型为 `gpt-image-1.5`，可用 `OPENAI_IMAGE_MODEL` 指定同接口的 GPT Image 模型。共用的服务端调用位于 `src/integrations/openai/images.ts`，其他业务可以传入提示词及可选参考文件，取得 PNG 字节。

从图片或提示词节点右侧连到配置节点左侧，可连接多个输入、共用输入；配置节点中上下调整顺序，图片对应“图1、图2”，多个提示词换行合并。填写输出文件名和步数，点击配置节点标题，在右下角预览、复制或下载 JSON。配置等待前序图片上传或生成、读取成功及修改保存后开放导出。缺失输入或参数错误会显示具体原因。

业务定义与实现见 [src/ext/ai-video/README.md](src/ext/ai-video/README.md)。`0003_ai_video.sql` 新增 `ext_ai_video_nodes`，基础表没有业务字段。`runtime/attachments.ts` 提供通用业务数据挂载，复用现有保存与撤销；`storage/extensions.ts` 让业务表参与同一事务。

JSON 的图片路径相对于 `data/ext/ai-video/`；执行你自己的视频函数时，应把输入根目录指向该目录，或将图片和 JSON 一起带走。文件替换和节点删除保留原图片以支持撤销，本轮没有自动清理。视频流程输出 JSON 配置，由你自己的视频函数执行。
