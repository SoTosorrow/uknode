# uknode

本地节点与连线编辑器。支持节点和连线编辑、多父级收录、按范围浏览与独立布局，以及 SQLite 自动增量保存和会话撤销重做。节点以短 ID 显示，没有名称、笔记等业务字段。界面采用细线框节点、点阵画布和悬浮工具条，支持框选与右键菜单。

## 运行

需要 Node.js 24。在项目根目录运行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。同一命令启动 Vite 和本地 Fastify 服务，前端的 `/api` 请求代理到服务端。

正式本地运行：

```sh
npm run build
npm start
```

打开 http://127.0.0.1:3000 。Fastify 通过官方插件 `@fastify/static` 提供构建后的 HTML、JavaScript 和 CSS，页面与 API 同源。服务仅监听本机，不把 SQLite 文件交给浏览器读取。

数据库默认位于 `data/uknode.sqlite`，首次启动自动创建目录和数据库并执行迁移。可用 `UKNODE_DATA_DIR` 指定其他目录，`PORT` 修改后端端口。数据库、依赖和构建产物不提交 Git。请始终从项目根目录运行命令。

## 数据库定义与同步

**表结构的定义来源是 [`src/backend/schema.ts`](src/backend/schema.ts)**。里面明确声明表名、字段、主键、外键、索引和检查约束：

| 定义 | SQLite 表 | 职责 |
| --- | --- | --- |
| `baseNodes` | `base_nodes` | 节点 ID、创建与更新时间；没有业务字段 |
| `baseEdges` | `base_edges` | 两端节点 ID、方向、可选说明及时间 |
| `baseMemberships` | `base_memberships` | 直接收录关系，多父级且禁止包含循环 |
| `viewNodeLayouts` | `view_node_layouts` | 各范围的独立坐标；`context_node_id` 为空表示全局画布 |
| `baseStoreState` | `base_store_state` | 当前修订号 |
| `baseBatchReceipts` | `base_batch_receipts` | 最近 1,000 个批次的幂等回执；没有操作内容 |

`base_schema_migrations` 由 Drizzle 管理，用于记录已执行的迁移；名称在 `drizzle.config.ts` 和服务启动配置中一致指定。

修改表结构的流程：

1. 修改 `src/backend/schema.ts`。
2. 运行 `npm run db:generate -- --name=变更名称`，由 Drizzle Kit 生成 `migrations/` 下的 SQL 与结构快照。
3. 查看生成的 SQL。变更已有数据前，先备份当前数据库。
4. 运行 `npm run db:migrate`，将迁移应用到 SQLite；启动服务也会应用尚未执行的迁移。
5. 将表定义和迁移文件一起提交。不要只改数据库而遗漏代码定义。

初始迁移为 `migrations/0000_initial.sql`；`0001_memberships_and_scoped_layouts.sql` 增加收录关系和范围布局，保留旧坐标为全局布局。布局表使用“范围＋节点”唯一索引，另用部分唯一索引确保空范围下的节点也只能有一条坐标。

启动服务不会按运行时对象猜测字段，也不会清空重建数据库。修改 schema.ts 后必须先生成并审阅迁移，才能把结构变化应用到数据库。已有数据上的破坏性结构变更仍需单独确认。

## 操作与保存

- 点击底部“新增节点”，或右键画布空白处新增；右键新增使用鼠标所在的画布位置。
- 拖动节点调整坐标。悬停或选中节点时显示连接点，从右侧连接点拖到另一节点左侧连接点创建连线。
- 点击节点，在右下角查看现有 ID 和坐标；点击连线，在同一详情卡编辑说明与方向。详情卡可折叠，折叠状态只保留在本页会话。
- 左键拖动空白处框选完整包含的节点；Shift 点击节点可追加选择。选区支持整体移动、删除和撤销。多选详情显示选中数量。
- 右键节点打开“新增节点／删除节点”菜单。右键未选节点会切换为单选；右键已选节点会保留多选，删除这些节点及其关联连线。空白处菜单禁用删除。
- 选中节点或连线，点击“删除选中”；删除节点会同时删除关联连线和坐标。
- 使用“撤销”“重做”或 Ctrl/⌘ Z、Ctrl/⌘ Shift Z。输入框内仍使用浏览器原生文字撤销。
- 按住空格再拖动，或按住鼠标中键拖动来平移；使用滚轮或左下角控件缩放、适应画布。
- 右键菜单支持方向键选择和 Enter 执行；按 Escape、点击外部或移动视口关闭菜单。

## 收录弹窗

- 单击节点选中，双击节点或点击详情里的“查看收录节点”，打开可编辑画布弹窗。弹窗只显示母节点的直接成员和成员之间的普通连线；母节点显示在标题中，间接成员需要逐层打开。
- 在弹窗顶部选择已有节点并点击“收录”。同一节点可以被多个节点收录，也可以自己收录成员；直接或间接包含自身会被拒绝。
- 在弹窗内继续打开节点，复用同一个弹窗。顶部显示浏览路径，“返回”回到之前浏览的母节点。点击关闭或按 Esc 回到主画布，保留主画布的缩放、平移和仍然存在的选中对象。
- “解除收录”只删除当前母节点的直接收录关系，成员立即从当前弹窗移出；节点、其他母节点的收录、普通连线和保存的布局都保留。即使还有间接路径，也不会混入直接成员画布。
- 弹窗工具栏和右键菜单分别提供“解除收录”和“彻底删除”。在弹窗内按 Delete / Backspace，选中节点时解除收录，仅选中连线时删除连线。涉及共享关系的彻底删除会提示影响范围。
- 在弹窗中新建节点，会同时创建节点、直接收录关系和当前母节点下的坐标；引用已有节点不复制对象。空母节点也可以从弹窗顶部收录已有节点。
- 每个范围独立保存坐标。没有坐标时使用初始网格，浏览本身不写数据库；拖动结束才保存。解除收录保留布局，重新收录可恢复之前摆放的位置。
- 主画布的“删除选中”及“删除节点”仍是彻底删除，会清理所有相关收录、连线和范围布局；未选中的子成员保留。批量解除收录和彻底删除都可以一次撤销。
- 右键菜单内按 Esc 先关闭菜单，再次按 Esc 才关闭弹窗。弹窗关闭后保存队列继续工作；浏览路径仅保留在本次弹窗内，刷新回到主画布。

普通连线允许成环、自连接和同端点多条边。

编辑先更新前端内存，并按对象合并待保存变更。拖动结束提交坐标；连线文字停止输入 500 毫秒后提交，失焦时立即提交。批次逐一发送到后端，事务内检查修订号并增量写入当前表。

发送中的批次固定 ID 和内容；期间的新修改进入下一批。响应丢失时重试相同批次，服务端先查幂等回执，避免重复执行。只在收到对应回执后显示已保存。失败时保留修改；修订冲突停止写入，不自动覆盖其他页面的数据。“重新读取”需要确认放弃本页尚未确认的修改。

前端最多保留当前会话 100 个撤销动作。没有永久历史或 IndexedDB 草稿恢复；异常关闭可能丢失尚未确认的修改。刷新会清空会话撤销记录。

## 代码位置与验证

- `src/frontend/`：页面、图数据状态、变更队列和会话撤销。
- `src/backend/`：本地服务、接口、Drizzle 表定义和 SQLite 事务。
- `src/shared/`：基础类型、直接成员与后代查询、包含循环检查，以及增量提交协议。
- `src/frontend/scope.ts`：从全库数据计算直接成员、成员之间的连线和独立坐标；`membership-dialog.tsx` 提供弹窗和浏览路径；`scope-controls.tsx` 提供收录选择和详情入口。
- `migrations/`：Drizzle Kit 生成的结构迁移。
- `tests/`：真实 SQLite/Fastify 测试，以及通过 Axios 适配器验证保存队列。

```sh
npm test
npm run build
```

`npm run build` 包含前后端 TypeScript 检查。测试包含旧结构迁移、范围布局隔离、循环事务回滚、收录变更合并、跨范围删除撤销、直接成员展示与主画布选择恢复。已确认范围见 `design.md` 的 1.3～1.6 节；其他产品目标留待逐轮确认。
